```markdown
### Summary
Added [MCP-Studio](https://github.com/mohsen-niksirat/Mcp-Studio) to the Clients/Tools section.

MCP-Studio is an open-source visual testing studio (the "Postman for MCP") that enables developers to:
- Test MCP tools using dynamic forms auto-generated from JSON Schema.
- Run an AI Chat Sandbox with autonomous function calling (Gemini, Ollama, OpenAI).
- Inspect live bidirectional JSON-RPC 2.0 traffic with latency tracking.
- Test in-browser via GitHub Pages without installation, or run locally on Windows/Linux/macOS.
```
